## Payment / PayOS implementation notes (BE)

### What was done

- **PayOS env template**: added `BEDMS/env.example` so you can copy to `.env` and paste real PayOS keys.
- **PayOS integration**:
  - Added `src/services/payos.service.js` (SDK init, create/get/cancel payment link, webhook verify).
  - Booking flow `submitBooking()` now creates a **real PayOS payment link** and persists a `Payment` record.
- **Payment status (real)**:
  - `GET /v1/bookings/:id/payment-status` now checks PayOS and returns:
    - `paid=false` + message **"Chưa thanh toán"** when still pending
    - `paid=true` + finalize booking when paid (invoice paid, bed occupied, contract created)
- **Auto-cancel after 10 minutes**:
  - Added `src/jobs/bookingExpiryScheduler.js` running every minute.
  - When expired: releases bed, restores room availability, cancels invoice, best-effort cancels PayOS link.
- **Webhook + email**:
  - Added `POST /v1/payos/webhook` to receive PayOS webhook, verify signature, then finalize booking (idempotent).
  - Added `src/services/email.service.js` (nodemailer) and send mail on successful payment (best-effort, configurable via SMTP env).

### Required env to run real PayOS

Copy `BEDMS/env.example` → create `BEDMS/.env` and fill:

- `PAYOS_CLIENT_ID`
- `PAYOS_API_KEY`
- `PAYOS_CHECKSUM_KEY`
- `PAYOS_RETURN_URL`
- `PAYOS_CANCEL_URL`

### Webhook endpoint

- Configure PayOS webhook to: `POST {BE_BASE_URL}/v1/payos/webhook`
